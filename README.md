A single dad joke, for the make.fun `u-mfnakmal-dad-joke-showdown-1d2ce3e5` bounty:

> I told my wife to embrace her mistakes. She gave me a hug.

Short, clean, and the punchline turns the idiom back on the teller.

## Run it

```sh
python3 main.py
```

Python 3, standard library only. Writes the entry to `/output/entry.txt`.
